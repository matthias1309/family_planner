# Moduldesign

Pro Feature-Modul eine Datei `<modul>.md` (z. B. `tasks.md`), erstellt mit `/ecc:plan` bevor implementiert wird.

Inhalt je Modul:

- Abgedeckte Anforderungen (REQ-IDs)
- Domänenmodell (Entitäten, Zustände)
- Schnittstellen: Endpunkte (Verweis auf `api/openapi.yaml`), publizierte/konsumierte Events
- DB-Tabellen und Migrationen
- Testfälle auf Unit-Ebene
